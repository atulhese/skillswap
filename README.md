# 🔄 Skill Swap Management Platform

A full-stack web application that allows users to exchange skills with other users. Users can add the skills they can offer, specify the skills they want to learn, find mutual skill matches, send swap requests, accept or reject requests, and manage active and completed skill swaps.

---

## 📌 Project Overview

The **Skill Swap Management Platform** is designed to connect people who want to learn new skills with people who can teach those skills.

For example:

- User A knows **Java** and wants to learn **Python**
- User B knows **Python** and wants to learn **Java**

The platform identifies this as a mutual skill match.

Both users can exchange their knowledge through a skill swap.

The application provides features for:

- User registration
- User login
- Adding offered skills
- Adding wanted skills
- Finding mutual skill matches
- Sending skill swap requests
- Accepting or rejecting swap requests
- Viewing active swaps
- Completing swaps
- Managing user skills

---

# 🚀 Features

## 👤 User Management

Users can:

- Create a new account
- Login using email and password
- Access their personal dashboard
- Logout from the application

---

## 🛠️ Skill Management

Each user can add skills in two categories.

### Skills I Can Offer

These are skills that the user can teach.

Examples:

- Java
- Python
- SQL
- React
- HTML
- Spring Boot

### Skills I Want to Learn

These are skills that the user wants to learn from another user.

Examples:

- Machine Learning
- JavaScript
- Node.js
- Data Analysis
- Cloud Computing
